# Java & MySQL Course Management Starter (Lab Assignment 1)

A Java Maven starter project demonstrating database connectivity and schema initialization using MySQL.

## Overview
This application establishes a direct connection between a Java environment and a local MySQL server to set up and verify a course management database.

## Key Features & Completed Tasks
- **Database Connectivity:** Configured JDBC to connect the Java Maven project with MySQL.
- **Database Initialization:** Verified and created the `StudentsDB` database.
- **Schema Design:** Built the `students` table structured for course management tracking.
- **Table Columns:** Defined fields for `id`, `firstname`, `lastname`, `student_email`, `enrollment_year`, and `grade`.
- **Data Seeding:** Inserted sample student records and validated the table schema.

## Prerequisites
- Java Development Kit (JDK)
- Apache Maven
- MySQL Server
